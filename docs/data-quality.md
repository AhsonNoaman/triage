# Data quality

Generated by `scripts/quality_report.py` from `data/complaints.parquet`. Regenerate with `make quality`.

Measured 2026-08-10 over **396,952** in-scope narrative complaints, 2021-01-01 to 2025-12-31, across 5 raw product labels.

---

## 1. Redaction, and what survives it

The CFPB scrubs narratives before publication, replacing redacted spans with runs of
`X`. This matters more than a typical data-quality note, because the obligations the
agent must check are made of exactly what a scrubber removes: Reg E's 10-business-day
investigation window, Reg Z's 60-day assertion window, and the $50 / $500 liability
tiers are all keyed to a date or an amount in the complaint.

| Property | Complaints | Share |
|---|---:|---:|
| Narrative contains at least one redacted span | 294,066 | 74.08% |
| Contains a **surviving** dollar amount (`$35.00`) | 158,911 | 40.03% |
| Contains a **redacted** dollar amount (`{$XX.00}`) | 9,347 | 2.35% |
| Contains a **surviving** date (`3/14/2025`) | 274 | 0.07% |
| Contains a **redacted** date (`XX/XX/XXXX`) | 131,038 | 33.01% |

Redacted spans per narrative: median 5, mean 11.1, max 4,004.

Narrative length in characters: median 733, mean 1,118, p10 226, p90 2,293, max 32,785.

## 4. ZIP code shape

DESIGN.md described this field as a partial ZIP. It is not uniformly partial, which is worth stating plainly: some rows carry a full five-digit code.

| Shape | Complaints | Share |
|---|---:|---:|
| full 5-digit | 292,911 | 73.79% |
| truncated (123XX) | 92,550 | 23.32% |
| other | 11,491 | 2.89% |

Nothing in the model reads geography, so this is recorded rather than acted on. It is in the report because a public repository should say what identifying detail its data carries, not because the agent uses it.
